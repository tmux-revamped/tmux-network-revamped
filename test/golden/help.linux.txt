$ network-revamped help
network-revamped - network throughput in the status bar

usage:
  network-revamped apply          bind the key and fill the placeholders
  network-revamped list           print what apply would send to tmux
  network-revamped status NAME    print one placeholder: download, upload,
                                  speed, fg_color, bg_color, vpn, vpn_name,
                                  ip, wifi, ssid, connections, ping,
                                  public_ip or online
  network-revamped refresh        sample the network now for the status line
  network-revamped card           print every reading as a table
  network-revamped popup          open the card in a tmux popup
  network-revamped daemon         publish the placeholders on every tick, for
                                  the options render mode
  network-revamped doctor         check this machine
  network-revamped version        print the version
  network-revamped help           print this page

keys:
  --popup-key KEY            the prefix key for the detail popup, or off

sampling:
  --interface NAME           the interface to measure; empty follows the
                             default route
  --interval SECONDS         how long a rate sample stays fresh
  --precision DIGITS         decimal places of a rate, 0 to 9
  --smoothing PERCENT        weight of the previous rate in a moving
                             average, 1 to 99; 0 shows each sample
  --render MODE              jobs or options

probes:
  --ping-enabled 0|1         1 pings 8.8.8.8
  --public-ip-enabled 0|1    1 asks icanhazip.com for the public address
  --online-enabled 0|1       1 requests www.gstatic.com<path>, or
                             pings when curl is missing
  --PROBE-interval SECONDS   how long one probe stays fresh: vpn, vpn-name,
                             ip, connections, wifi, ssid, online, ping or
                             public-ip

formats:
  --speed-format FORMAT      printf format for download, then upload
  --ping-format FORMAT       printf format for the latency
  --wifi-format FORMAT       printf format for the signal
  --online-up-text TEXT      what #{net_online} prints when reachable
  --online-down-text TEXT    what it prints when not reachable
  --icons SET                ascii, or nerd for a Nerd Font glyph before
                             every metric
  --METRIC-label TEXT        the label before one metric
  --fixed-width on|off       on pads every value to its widest form
  --METRIC-width COUNT       the width of one metric

tiers:
  --medium-thresh KBPS       download plus upload that starts the medium tier
  --high-thresh KBPS         download plus upload that starts the high tier
  --TIER-fg-color STYLE      what #{net_fg_color} prints in the low, medium
                             or high tier
  --TIER-bg-color STYLE      what #{net_bg_color} prints in each tier

output:
  --json                     list prints one JSON object
  --theme NAME               the look: kodougu, catppuccin-mocha,
                             catppuccin-latte, dracula, nord, gruvbox,
                             tokyo-night or mono

environment:
  NETWORK_REVAMPED_<SETTING>   the same as the option of that name, such as
                               NETWORK_REVAMPED_INTERVAL for --interval
  NETWORK_REVAMPED_THEME       the look, when --theme is not given
  NETWORK_REVAMPED_ACCENT      a colour such as #CBA6F7 for the accent
  KODOUGU_THEME                the family look, when neither is given
  KODOUGU_ACCENT               the family accent, when the tool's is unset
  NO_COLOR                     turn colour off

tmux options:
  @net_revamped_popup_key            the detail popup key (default M-e)
  @net_revamped_interface            interface to measure (default none,
                                     the default route)
  @net_revamped_interval             seconds a rate stays fresh (default 2)
  @net_revamped_precision            decimal places of a rate (default 1)
  @net_revamped_smoothing            percent of the previous rate kept
                                     (default 0)
  @net_revamped_render               jobs or options (default jobs)
  @net_revamped_ping_enabled         1 turns the ping probe on (default 0)
  @net_revamped_public_ip_enabled    1 turns the public address probe on
                                     (default 0)
  @net_revamped_online_enabled       1 turns the reachability probe on
                                     (default 0)
  @net_revamped_vpn_interval         seconds between VPN link probes
                                     (default 30)
  @net_revamped_vpn_name_interval    seconds between VPN name probes
                                     (default 30)
  @net_revamped_ip_interval          seconds between LAN address probes
                                     (default 30)
  @net_revamped_connections_interval seconds between connection counts
                                     (default 30)
  @net_revamped_wifi_interval        seconds between signal probes
                                     (default 30)
  @net_revamped_ssid_interval        seconds between Wi-Fi name probes
                                     (default 30)
  @net_revamped_online_interval      seconds between reachability probes
                                     (default 30)
  @net_revamped_ping_interval        seconds between pings (default 15)
  @net_revamped_public_ip_interval   seconds between public address
                                     fetches (default 300)
  @net_revamped_speed_format         format of #{net_speed}
                                     (default "%s %s")
  @net_revamped_ping_format          format of #{net_ping} (default "%sms")
  @net_revamped_wifi_format          format of #{net_wifi}
                                     (default "%sdBm")
  @net_revamped_online_up_text       text when reachable (default on)
  @net_revamped_online_down_text     text when not reachable (default off)
  @net_revamped_icons                ascii or nerd (default ascii)
  @net_revamped_fixed_width          on or off (default off)
  @net_revamped_<metric>_label       label before one metric (default none)
  @net_revamped_<metric>_width       width of one metric (default none)
  @net_revamped_medium_thresh        KB<path> that starts the medium tier
                                     (default 100)
  @net_revamped_high_thresh          KB<path> that starts the high tier
                                     (default 1000)
  @net_revamped_<tier>_fg_color      style of #{net_fg_color} in the low,
                                     medium or high tier (default none)
  @net_revamped_<tier>_bg_color      style of #{net_bg_color} in each tier
                                     (default none)
  @revamped_theme                    the family look (default kodougu)

notes:
  A metric is download, upload, speed, vpn, vpn_name, ip, wifi, ssid,
  connections, ping, public_ip or online, written with dashes in an option,
  such as --vpn-name-label. The placeholders are #{net_<metric>},
  #{net_fg_color} and #{net_bg_color}. Each prints the stored reading at
  once, and starts one background sample when the rates are older than the
  interval. A probe runs only for a placeholder the status line uses. With
  --render options each placeholder reads a tmux option that a background
  process fills on every tick, so a status refresh starts no process.

examples:
  network-revamped status speed
  network-revamped card
  network-revamped --icons nerd --fixed-width on apply
  network-revamped list --json
exit 0
